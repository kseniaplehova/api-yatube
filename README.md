# Проект Yatube API

### Описание
REST API для социальной сети Yatube. Проект позволяет управлять публикациями, группами и комментариями через HTTP-запросы. Пользователи могут получать список постов и комментариев, а авторизованные пользователи — создавать новые записи, редактировать и удалять собственный контент.


### Технологический стек
* **Python** 3.9+
* **Django** 3.2+
* **Django REST Framework** (DRF)
* **Token Authentication** (DRF Authtoken)
